# Getting help

- **How do I…?** Open the **Docs** in the app (the book icon in the left rail): every feature has a short guide. The [README](README.md) covers installing, the command line and AI agents.
- **Questions and ideas:** [GitHub Discussions](https://github.com/LibreGuild/zorvik/discussions). Q&A for questions, Ideas for suggestions, Show and tell for what you built with Zorvik.
- **Something is broken:** [open a bug report](https://github.com/LibreGuild/zorvik/issues/new?template=bug_report.yml). Search the existing issues first; a 👍 on an existing one helps us prioritise.
- **Security problem:** report it privately; see [SECURITY.md](SECURITY.md).

Zorvik is maintained by volunteers, so answers can take a few days. Clear steps to reproduce get the fastest help.
