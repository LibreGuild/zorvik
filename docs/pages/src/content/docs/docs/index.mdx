Zorvik is an open-source desktop app to **build, test, mock and load test APIs**, **test and mock the MCP servers AI agents use**, and see what really happens on the network. It runs on Windows, macOS and Linux, and every download also has the `zorvik` command line for CI.

These pages explain every feature in detail. New to APIs? The [Training Bootcamp](bootcamp/training-bootcamp/) inside the app teaches you hands-on.

## How Zorvik is organized

<CardGrid>
  <Card title="Workspaces are files" icon="document">
    A workspace is a folder of readable YAML: requests, folders, environments, servers and load tests. Keep it in Git and review it in pull requests.
  </Card>
  <Card title="Secrets stay local" icon="seti:lock">
    Secret values, cookies and OAuth tokens live in the app's data folder, never in the workspace files.
  </Card>
  <Card title="One engine" icon="rocket">
    The app, the command line and AI agents all use the same Rust engine, so a request behaves the same everywhere.
  </Card>
  <Card title="Local first" icon="laptop">
    No account, no cloud sync, no tracking, and every feature is free. Zorvik works offline and behind corporate proxies; its only connection of its own is the update check to GitHub.
  </Card>
</CardGrid>
